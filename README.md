⚡ Google MCP Servers

Remote MCP servers

Google provides remote MCP servers for supported Google Cloud products and services. These services are managed by Google and are accessed through supported endpoints.

For the current list of generally available (GA) and public-preview remote MCP servers, please refer to Google's official documentation.

Examples include:

- AlloyDB for PostgreSQL
- BigQuery
- Bigtable
- Cloud Resource Manager
- Cloud SQL
- Compute Engine
- Developer Knowledge API
- Firestore
- Google Maps
- Google Security Operations
- Google Kubernetes Engine (GKE)
- Spanner
- Cloud Run
- Cloud Storage

Open-source MCP servers

Google also provides open-source MCP-related projects and examples that can be used locally or deployed to Google Cloud.

Examples include:

- Google Workspace
- Firebase
- Cloud Run
- Google Analytics
- MCP Toolbox for Databases
- Google Cloud Storage
- Genmedia
- Google Kubernetes Engine (GKE)
- Google Cloud Security
- gcloud CLI
- Google Cloud Observability
- Flutter/Dart
- Angular
- Google Maps Platform Code Assist toolkit
- Chrome DevTools

💻 Examples

Examples and sample applications can be found in Google's official MCP and Google Cloud documentation.
